## Free TTS Tools to Generate Audio

1. **ElevenLabs** (https://elevenlabs.io) — Free tier with 10,000 characters/month
   - Best quality, sounds very natural
   - Upload this script, generate audio per slide

2. **Google Text-to-Speech** (https://cloud.google.com/text-to-speech)
   - Free tier: 1M characters/month
   - Good quality, multiple voices

3. **Microsoft Edge TTS** (free, built into Edge browser)
   - Press Ctrl+Shift+S in Edge to read text aloud
   - Record with OBS Studio

4. **ttsmp3.com** (https://ttsmp3.com) — Free, no signup
   - Paste text, download MP3
   - Good for quick generation

5. **NaturalReader** (https://www.naturalreaders.com) — Free tier
   - Upload text, generate audio

### How to Combine
1. Generate audio for each slide separately using any tool above
2. Open OBS Studio (free)
3. Add the HTML demo as a "Window Capture" source
4. Add each audio file at the right timestamp
5. Record the full 3-minute video
6. Export as MP4
